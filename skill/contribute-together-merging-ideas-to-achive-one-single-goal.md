# Contribute Together: Merging Ideas to Achieve One Single Goal

## 1. State the Goal First
- Write the single goal in one sentence before any idea is discussed.
- Every idea is judged only by whether it moves this goal forward.

## 2. Collect Without Judging
- Each contributor lists ideas without critique in the first pass.
- Record the author of each idea so credit and questions stay traceable.

## 3. Group and Reduce
- Cluster ideas that solve the same sub-problem.
- Drop ideas that do not serve the goal. State the reason in one line.

## 4. Merge
- Take the strongest part of each overlapping idea and combine them into one proposal.
- Where ideas conflict, decide by the goal, not by seniority or volume.
- If the conflict cannot be decided, use [[how-to-escalate-things]].

## 5. Commit to One Direction
- Publish one merged plan with owners and next steps.
- After the decision, everyone executes the merged plan, including those whose idea was not chosen.

## 6. Rules
- No private forks of the plan. Changes go back to the shared plan.
- Disagree before the decision, not after.
- Keep the merged result as small as the goal allows.
