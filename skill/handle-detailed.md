# In-Depth Analysis Protocol (`handle-detailed`)

1. **Complete Architecture Context**: Explain the background, root cause, and technical design decisions thoroughly.
2. **Structural Clarity**: Use structured Markdown (tables, checklists, numbered steps, code blocks).
3. **Impact and Trade-off Analysis**: Detail upstream and downstream effects, system invariants, risks, and potential edge cases.
4. **Step-by-Step Breakdown**: Provide end-to-end procedures, verification steps, and expected outputs.
5. **Reproducibility**: Include exact commands, configuration parameters, and recovery instructions.
