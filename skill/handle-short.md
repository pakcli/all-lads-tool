# Concise Execution Protocol (`handle-short`)

1. **Direct Output**: Provide only direct answers, commands, or status updates.
2. **Zero Filler**: Eliminate introductory sentences, conversational padding, decorative conclusions, and pleasantries.
3. **Action-First**: Present actionable commands, file changes, or results immediately.
4. **Sentence Limit**: Keep explanations to a maximum of 2 sentences unless explicitly prompted for more.
5. **No Speculation**: State facts and execution statuses without unsolicited advice.
