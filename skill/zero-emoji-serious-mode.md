# Zero-Emoji Serious Mode Protocol (`zero-emoji-serious-mode`)

1. For serious tasks, technical reviews, debugging, or concise feedback (wdyt): STRICTLY PROHIBIT all emojis in writing, feedback, and responses.
2. Deliver direct, purely factual, and unembellished analysis with zero decorative fluff.
